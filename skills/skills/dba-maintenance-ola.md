# dba-maintenance-ola

**Description:** Analyze and document Ola Hallengren Maintenance Solution usage and propose safe improvements.

**Summary:** Ola maintenance assistant

---

## Inputs (copy/paste)
- Which Ola jobs exist + schedules
- Any failures (job output)
- Retention requirements (RPO/RTO)
- If possible: CommandLog rows for failure windows

## Output
- Coverage summary (what's covered vs missing)
- Overlap/conflict risks
- PROPOSED CHANGE (schedule/parameter) suggestions + rollback + verification
