# DBA Codex Agents (Skills) — Repo Setup

This repo now contains:
- AGENTS.md (Codex working agreements)
- .codex/skills/* (DBA task skills)
- templates/ (copy/paste templates)
- artifacts/ (suggested output folder)

## Using skills in Codex
1) Start Codex in this repo folder.
2) List skills: `/skills`
3) Invoke explicitly by typing `$` then selecting a skill (e.g., `$dba-agent`).

Suggested first run:
- Fill out templates/daily_input_template.md and paste it into Codex with `$dba-agent`.
