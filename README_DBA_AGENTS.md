# DBA Agents (Skills) — Repo Setup

This repo now contains:
- AGENTS.md (working agreements)
- skills/* (DBA task skills)
- templates/ (copy/paste templates)
- artifacts/ (suggested output folder)

## Using skills
1) Start the agent in this repo folder.
2) List skills: `/skills`
3) Invoke explicitly by typing `$` then selecting a skill (e.g., `$dba-agent`).

Suggested first run:
- Fill out templates/daily_input_template.md and paste it with `$dba-agent`.
