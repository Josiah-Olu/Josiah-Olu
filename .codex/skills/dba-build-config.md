# dba-build-config

**Description:** Produce SQL Server build/config checklists and repeatable scripts for SQL Server 2012–2022 on Windows.

**Summary:** Build + configuration helper

---

## Inputs (copy/paste)
- SQL Server version/edition, instance type
- Storage layout constraints
- HA requirements
- Any org standards

## Output
- Build checklist (pre-reqs, service accounts, ports, tempdb layout guidance)
- Post-build validation scripts (read-only)
- Job setup suggestions (operators/alerts/schedules)
